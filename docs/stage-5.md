# Stage 5 — Commuter PWA and terminal kiosk

## Built (`web/`, plain HTML/CSS/JS, served by the Node server)
- `index.html` + `app.js` + `styles.css`:
  - Leaflet 1.9.4 + OSM map with the route line, stop markers and live jeep markers.
  - Stale jeeps are gray with a dashed border **and** labelled "N · Xm ago", so color isn't the only cue. They're removed after 10 min.
  - Tap a stop, or pick it from the dropdown (keyboard accessible), to list "Jeep 104 — 3 min".
  - "Nearest stop" uses browser geolocation and is optional. If permission is denied, a message appears and the app keeps working.
  - An "Offline — reconnecting…" banner (`role="status"`) shows while the WebSocket is down.
- `live.js`: WebSocket client with reconnect backoff of 1 s → 30 s. It re-subscribes to the selected stop after reconnecting.
- `geo.js`: `nearestStop` (haversine).
- `kiosk.html` + `kiosk.js`: full-screen board for the terminal tablet. It shows the next 5 arrivals at the Grand Terminal in text ≥ 32 px and auto-updates over WebSocket. It also retries its first load. The outbound column says "Outbound not tracked yet" (see `docs/open-questions.md` §2).
- `manifest.json`, `sw.js` (caches the app shell only, never `/api` or `/ws`), and `icons/` (PNG icons generated by `icons/make_icons.py`).

## Run
Start the server (Stage 4), open `http://localhost:8080/` for the commuter app or `http://localhost:8080/kiosk.html` for the kiosk. Tests: `cd web && npm test` (5 pass).
